# 🚗 StandAuto

Aplicação de consola, em Python, para gestão de um stand de automóveis.
Projeto da UC **Ambientes de Desenvolvimento Colaborativo** — ISE, Universidade do Algarve (2026/2027).

## Funcionalidades
- Registar, consultar, editar e eliminar viaturas (CRUD)
- Pesquisar viaturas por matrícula, marca ou modelo
- Vender uma viatura (atualiza o estado)
- Guardar e carregar os dados em ficheiro JSON
