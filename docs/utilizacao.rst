Como utilizar
=============

Requisitos
----------

* Python 3.10 ou superior
* Não são precisas bibliotecas externas

Executar a aplicação
--------------------

Na pasta do projeto:

.. code-block:: bash

   python main.py

Menu principal
--------------

======  ===========================================
Opção   Ação
======  ===========================================
1       Registar viatura
2       Listar viaturas
3       Editar viatura
4       Eliminar viatura
5       Pesquisar viatura (matrícula, marca ou modelo)
6       Vender viatura
0       Guardar e sair
======  ===========================================

Os dados são guardados no ficheiro ``viaturas.json``.

.. note::
   A matrícula tem de seguir o formato ``AA-00-BB``.
