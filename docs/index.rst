StandAuto — Documentação
========================

**StandAuto** é uma aplicação de consola, em Python, para gerir as viaturas
de um stand de automóveis.

Projeto da UC *Ambientes de Desenvolvimento Colaborativo* — ISE, Universidade do Algarve.
